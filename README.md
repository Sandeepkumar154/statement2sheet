# 📊 Statement2Sheet — Every Financial & PDF Tool in One Place

> **The 100% in-browser, privacy-first PDF and Bank Statement suite. Zero server uploads, zero data exfiltration, $0 hosting cost forever.**

---

## 🌟 What is Statement2Sheet?
Statement2Sheet combines all standard PDF tools (Merge, Split, Organize, Rotate, Unlock, Watermark, Page Numbers, Compress, PDF to JPG) with an **enterprise-grade bank statement extraction and balance reconciliation engine** that converts bank statements from any country, currency, or layout into audited 3-sheet Excel and CSV files.

---

## 🛠️ Complete 10-Tool Suite
1. 📊 **Bank Statement to Excel (.xlsx) & CSV**: Universal semantic parser handling Indian Lakhs, European dates, century ambiguity, and multi-check grids with mathematical balance reconciliation.
2. 📑 **Merge PDF**: Combine multiple monthly bank statements or documents with visual cover previews and expandable page galleries.
3. ✂️ **Split PDF**: Extract specific pages with live high-resolution thumbnails, 3-way view size toggles, and 🔍 full-screen zoom inspection.
4. 🔄 **Organize & Rotate**: Rotate 90° or remove unwanted pages directly in browser memory with instant visual feedback.
5. 🔓 **Unlock PDF**: Remove permissions and decrypt PDFs locally in browser memory.
6. 🏷️ **Watermark PDF**: Add custom text watermarks with custom opacity and font sizes.
7. 🔢 **Page Numbers**: Stamp automated formatted page numbers.
8. 🖼️ **PDF to Image**: Render high-resolution JPG/PNG images from PDF pages.
9. 📸 **Image to PDF**: Combine smartphone receipts and statement photos into a unified PDF.
10. 🛡️ **Audit Inspector**: In-depth balance reconciliation auditor.

---

## 🔒 100% Client-Side Privacy
* Zero document bytes, account numbers, or balances leave your device.
* All parsing, OCR, and PDF assembly execute in browser memory via WebAssembly and HTML5 TypedArrays.
* Immune to server-side data breaches.
